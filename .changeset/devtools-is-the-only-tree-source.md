The accessibility tree is read through the browser's DevTools port on every operating system and in whichever browser a launch gives, and the companion extension is removed. A chromium project is launched with `--force-renderer-accessibility` and `--remote-debugging-port` and nothing else: no `--load-extension`, no `--allowlisted-extension-id`, no `--disable-features` override, Playwright's `--disable-extensions` is left on, and a headless launch is no longer given `channel: "chromium"`, so it runs in Playwright's headless shell. There is no automatic pick of a tree source, no fallback from the extension and no option to choose one; `ANNOUNCEMENT_EMULATOR_TREE` and `ANNOUNCEMENT_EMULATOR_EXTENSION_WAIT` are no longer read, and a run that finds the first set prints one line saying it is ignored. A report says `treeSource: "devtools"`, no longer carries `treeSourceWhy`, a fallback record or the words "lower fidelity", and its agreement line is the DevTools figure for the operating system (`devtools-linux`, `devtools-macos`; the `extension-linux` figures are dropped from `supported-versions.json`). The bundle no longer carries the extension.
