The package is named `@a11ign/foresay` (it was `@a11ign/announcement-emulator`) and its command is `foresay` (`npx foresay install`, `doctor` and `test`); the messages it prints say `foresay`. It is licensed Apache-2.0, with a `LICENSE` and a `NOTICE` in the tarball, and a test fails if the tarball holds a file of the runtime. The runtime bundle declares `GPL-3.0-or-later` in its `bundle.json` and ships the GPL text and a `NOTICES` file (the source offer and the notices of NVDA, Chromium's tables, the CLDR names, Python and its packages). The README says what the tool is in one sentence: "Predicts what the NVDA screen reader would say, built on NVDA's open-source code. Not affiliated with NV Access." The package stays private, so nothing is published; the environment variables, the cache directory and the bundle's file names keep the repository's name until it is renamed.
